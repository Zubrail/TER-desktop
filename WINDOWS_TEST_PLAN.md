# TER для Windows — что проверить (по опыту Mac, 13.10.2026)

Тест-стенд: Windows 11 ARM в UTM на Mac владельца (x64-сборка идёт через эмуляцию Windows; позже — сборка win-arm64).
Сборка: `package-ter-win.sh` → `dist/TER-<ver>-win-x64.zip`. Ядра из официальных релизов, суммы сверены (`cores/win`).
Доступ: OpenSSH Server в Windows. GUI из SSH не видно (сессия 0) — тур запускать задачей планировщика
в сессии пользователя (`schtasks /create ... /it`), снимки `ter-shot-*.png` забирать по scp.

| # | Что | Почему (что было на Mac / чем отличается Windows) | Как проверяем |
|---|-----|------|------|
| 1 | Весь трафик (TUN) | Mac: пароль sudo, 0.6.1 висел, т.к. окно upstream не регистрировалось. Windows: нужны права администратора (upstream делает RebootAsAdmin). Наш EnsureTunAsync на не-Mac выходит сразу | сделать своё окно «Перезапустить TER с правами администратора» или запуск всегда «от администратора» (manifest), проверить wintun, сайт, Telegram |
| 2 | Трей | TermitusTray — нативный NSStatusItem/NSMenu macOS | на Windows — TrayIcon Avalonia: левый клик = окно, правый = меню (Подключить, страна, Выход) |
| 3 | Обновление | Mac заменяет .app; Windows не даёт заменить запущенный .exe | updater: скачать zip → распаковать рядом → маленький bat/второй процесс после выхода переименовывает папку; проверка подписи как на Mac |
| 4 | «Включён другой VPN» | парсит `netstat -rn` macOS | Windows: `route print` / GetBestRoute, адаптеры TAP/WireGuard/wintun; тест с выключенным/включённым другим VPN |
| 5 | SmartScreen / Defender | неподписанный exe = «Windows защитила компьютер»; xray.exe иногда «riskware» | инструкция «Подробнее → Выполнить в любом случае»; проверить, что Defender не удаляет ядро; позже — подпись кода |
| 6 | Права на файлы | Mac 0700/0600 (Unix) | на Windows этот код пропускается; данные в %APPDATA%, не рядом с exe (NotStoreConfigHere) |
| 7 | Эмодзи-флаги | Mac 0.4.1: флаги в именах серверов вешали интерфейс | Segoe UI Emoji; проверить скорость переключения страниц (TER_PERF) |
| 8 | Прозрачность окна, тёмная тема | AcrylicBlur на Mac; Windows 10/11 по-разному | обе темы, снимки всех экранов |
| 9 | DNS/IPv6 утечки | на Mac закрыто в 0.3 (strict_route, hijack-dns) | dnsleaktest / ipleak при TUN, IPv6 выключен в туннеле |
| 10 | Автозапуск | Mac — LaunchAgent | Windows — реестр Run (upstream), проверить перезагрузку |
| 11 | Один экземпляр | мьютекс TER, второй запуск показывает окно | двойной запуск |
| 12 | Оплата, поддержка, вход через Telegram, Аккаунт 2.0 | общий код, но открытие ссылок (браузер/Telegram) через ОС | каждая кнопка вживую |
| 13 | Пути и логи | «Пароль sudo», пробелы в пути на Mac | `C:\Users\Имя\...` с кириллицей и пробелом; отчёт о проблеме не содержит имени пользователя |
| 14 | Kill switch | Mac через системный прокси | Windows: системный прокси (реестр WinINet) — проверить, что при обрыве браузер не идёт напрямую |
